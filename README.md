# GronnFalk Uptime

[![Uptime Check](https://github.com/LiamProsser77/gronnfalk-uptime/actions/workflows/uptime.yml/badge.svg)](https://github.com/LiamProsser77/gronnfalk-uptime/actions/workflows/uptime.yml)

Monitors GronnFalk websites and search functionality.

## Monitored Services

- [GronnFalk GitHub Pages](https://liamprosser77.github.io/gronnfalk/)
- [GronnFalk Render](https://gronnfalk-space.onrender.com/index.html)
- [Render Search API](https://gronnfalk-api-aijg.onrender.com/)

Checks run every 15 minutes using GitHub Actions.

The checker verifies website availability and tests whether the search API returns valid, non-empty results.
